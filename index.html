My Strategy

UI Development

웹 퍼블리싱 전반을 담당하며, 공통화·재사용이 가능한 CSS 구조를 설계하여 유지보수와 확장을 고려한 UI를 구현합니다.

Responsive Markup

웹 표준을 준수하며, 의미있는 마크업을 작성합니다.
미디어쿼리를 활용하여 반응형 레이아웃을 구현할 수 있습니다.

Scripting

jQuery와 JavaScript를 활용하여 UI 인터랙션 및 화면 기능을 구현하며, 라이브러리 구조를 이해하고 요구사항에 맞게 커스터마이징할 수 있습니다.

Co-work

기획·디자인·개발 간의 업무 흐름을 이해하고, 의도와 구현 간의 간극을 줄이기 위해 능동적으로 소통하며 협업합니다.
